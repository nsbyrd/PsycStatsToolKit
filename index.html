Software

Jamovi

Jamovi is a free, point-and-click statistics program which is a great place to start if you're not ready to write code yet. Download it at jamovi.org/download.

R

R is a free programming language for statistics, which is a more flexible way to do analyses. Download R at cran.r-project.org, and I'd also recommend RStudio as the interface to write and run it in.
